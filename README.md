# Nepal Landslide Risk Prediction Using Machine Learning

## Overview

This project investigates whether machine learning can estimate landslide susceptibility in Nepal using historical landslide observations and environmental features.

The project aims to compare machine learning models, evaluate their ability to generalize to geographically separate areas, and visualize their predictions.

## Research Questions

1. How well can machine learning models distinguish landslide-prone locations from suitable non-landslide samples?
2. How does model performance change when evaluation is performed on geographically separate areas?
3. Which environmental features contribute most to the model's predictions?

## Planned Technologies

* Python
* pandas and NumPy
* scikit-learn
* Matplotlib and Seaborn
* GeoPandas and other GIS tools, as needed

## Planned Workflow

1. Obtain and inspect a Nepal-specific landslide inventory.
2. Clean the data and investigate its limitations.
3. Prepare appropriate landslide and non-landslide samples.
4. Train and compare baseline machine learning models.
5. Evaluate performance using geographically appropriate validation.
6. Create and interpret a landslide susceptibility visualization, if supported by the available data.

## Current Status

Initial development: project setup and environment configuration.

## Limitations

This is a research prototype, not an operational landslide early-warning system. Susceptibility estimates do not predict the exact timing of a landslide.
